# XP and quests

XP exists to reward doing, not passive reading.

Examples:
- finish a hands-on lesson;
- solve a network quest;
- identify hardware correctly;
- fix a disposable lab;
- understand a systemd problem.

XP/state is stored locally in:

```text
~/.local/share/kali-academy/state.json
```

It is not automatically committed to GitHub.

## Philosophy

Hints are allowed.
Blind answer-copying should not be rewarded.

A quest typically asks you to:
1. inspect;
2. form a hypothesis;
3. use a tool;
4. interpret evidence;
5. explain the result.

Pip acts as a coach rather than simply dumping the solution.
