# Security

Kali Academy is built for legal learning and diagnostics.

Use security tooling only on:
- your own systems and networks;
- the isolated Academy cyber range;
- or systems/networks whose owner explicitly authorized the testing.

Do not commit:
- passwords;
- LUKS passphrases;
- SSH private keys;
- API tokens;
- Wi-Fi credentials;
- packet captures containing private traffic;
- recovered personal files.

The learner profile is stored locally outside the Git repository by default.
